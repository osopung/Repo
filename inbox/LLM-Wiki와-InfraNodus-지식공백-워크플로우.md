# LLM Wiki와 InfraNodus를 결합한 지식공백 탐색

## 출처

채널 「평범한 사업가」의 영상  
「Karpathy LLM Wiki를 가장 강력하게 구축하는 방법. InfraNodus로 Obsidian과 LLM을 활용한 지식 기반 워크플로우 구축하기」

## 핵심 요약

일반적인 RAG는 문서를 검색해 답변하는 데는 유용하지만, 지식이 장기적으로 연결되고 진화하는 구조를 만들기 어렵다. Karpathy의 LLM Wiki 방식은 원자료를 개념과 연결 중심의 Markdown 위키로 정리해 이 한계를 보완한다.

그러나 위키가 있어도 LLM은 기존 연결을 반복하거나 뻔한 답변을 만들 수 있다. 이 영상은 InfraNodus를 결합해 지식 그래프의 군집과 군집 사이의 구조적 공백을 찾고, 그 공백을 새로운 질문과 연구 과제로 바꾸는 방법을 제안한다.

## 제안된 구조

```text
raw
├── 원자료·PDF·메모

wiki
├── 개념
├── 출처
└── 개념 사이의 연결

output
└── 분석을 통해 나온 아이디어

todo
└── 앞으로 탐색할 질문과 연구 과제

.infranodus
└── 지식 그래프 분석을 위한 구조
```

## 워크플로우

```text
자료 수집
→ 개념·핵심 주장·인용·연결 추출
→ Markdown 위키 생성
→ 지식 그래프 시각화
→ 분리된 군집과 구조적 공백 발견
→ 공백을 연결하는 질문 생성
→ LLM으로 새로운 통찰과 연구 과제 도출
```

## 중요한 개념

### 1. 지식 그래프

문서와 개념을 단순한 목록으로 저장하지 않고, 서로 어떤 관계를 맺는지 네트워크로 표현한다.

### 2. 구조적 공백

서로 가까이 연결되지 않은 개념 군집 사이의 빈틈이다. 이 공백은 단순한 누락이 아니라 새로운 질문과 창작의 출발점이 될 수 있다.

### 3. 질문 생성

서로 떨어져 있는 두 군집을 연결해 다음과 같은 질문을 만든다.

> 왜 이 두 주제는 함께 나타나지 않는가?  
> 두 주제를 연결하면 어떤 새로운 해석이나 연구 방향이 가능한가?

## 오소풍_wiki에 적용할 때의 해석

이 영상의 전체 시스템을 그대로 옮기기보다, 오소풍_wiki에는 다음 부분만 선택적으로 참고할 수 있다.

```text
경험·작품·자료
→ 반복되는 개념과 질문 발견
→ 서로 떨어져 있는 주제 확인
→ 두 주제를 잇는 질문 제안
→ 에세이·영상·시화의 창작 재료로 발전
```

예를 들면 다음과 같은 연결이 가능하다.

```text
토란 손질 ── 시행착오 ── 삶을 익혀 가는 과정
『우리가 볼 수 없는 모든 빛』 ── 보이지 않는 연결 ── 라디오 전파
LLM Wiki ── 지식의 연결 ── 창작의 질문
```

이때 연결은 사실·해석·추측을 구분해야 한다.

- **사실:** 토란을 직접 손질하고 토란국을 만들었다.
- **해석:** 토란 손질을 낯선 삶을 익히는 과정으로 읽을 수 있다.
- **제안:** 이 경험을 영상 에세이의 소재로 발전시킬 수 있다.

## 적용 시 주의점

- 원자료 전체를 위키에 복사하지 않는다.
- 지식그래프와 전수 태깅을 의무화하지 않는다.
- 모든 문서에 복잡한 온톨로지를 적용하지 않는다.
- LLM이 만든 연결을 확인된 사실로 저장하지 않는다.
- 실제로 반복해서 꺼내 쓰는 경험·작품·질문 사이에만 선택적으로 연결한다.
- InfraNodus는 편집 체계가 아니라 관계와 공백을 발견하는 보조 도구로 본다.

## 남는 질문

1. 오소풍_wiki에서 반복되지만 아직 서로 연결되지 않은 주제는 무엇인가?
2. 경험과 작품 사이에 어떤 질문의 공백이 있는가?
3. `related` 또는 `question` 같은 선택적 필드가 실제로 도움이 되는 문서는 무엇인가?
4. 지식 그래프가 창작의 자유를 넓히는가, 아니면 분류 부담을 키우는가?

## 한 줄 정리

> 지식을 많이 쌓는 것보다, 서로 만나지 않던 경험·작품·질문 사이의 빈틈을 발견하고 그것을 새로운 창작 질문으로 바꾸는 것이 이 워크플로우의 핵심이다.
