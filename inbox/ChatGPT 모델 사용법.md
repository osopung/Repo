# ChatGPT 모델 사용법

- 작성일: 2026-09-06
- 작성자: 고문 (윈도우 Cursor)
- 출처: 챗지피티(Work Agent) 화면의 「사용량」 팝업을 보고 정리
- 범위: 윈도우 ChatGPT 채팅의 모델 한도. 헤르메스의 Luna(Nexos)와는 다른 말이다.

## 한 줄

고급 모델을 다 쓰면 채팅이 멈추는 게 아니라, **Luna**라는 가벼운 모델로 바뀐다. 고급 모델을 다시 쓰려면 시간을 기다리거나, 재설정을 쓰거나, 플랜·크레딧을 산다.

|------|------------------------------|----|
| 5시간 사용 한도 | 0% 남음 · 오후 4:44 재설정 | 고급 모델을 **짧은 창**으로 나눠 쓰는 양. 바닥나면 그 창이 끝날 때까지 고급 모델 불가. |

버튼: **플랜 업그레이드** · **크레딧 추가**. 채팅창에도 「Upgrade」·「Reset usage」가 뜬다.

## 고급 모델이 막혔을 때

1. **그냥 이어가기** — Luna로 된다. 간단한 일·짧은 질문은 이걸로 충분할 수 있다. 어려운 일·긴 작업은 약해질 수 있다.
2. **기다리기** — 5시간 한도 재설정 시각(그날은 오후 4:44)까지 두면 고급 모델이 다시 열린다.
3. **재설정 1번 쓰기** — 남은 횟수가 있으면 바로 고급 모델로 돌아간다. 횟수는 무한하지 않다.
4. **돈으로 열기** — 플랜 업그레이드, 또는 크레딧 추가.

## 헷갈리지 말 것

- 여기 **Luna** = ChatGPT가 고급 모델 한도가 떨어졌을 때 켜는 **가벼운 대체 모델**.
- 집의 **헤르메스 Luna** = VPS 쪽 메인 모델(Nexos). 같은 이름이지만 다른 자리.

## 실무 메모

- 고급 모델이 필요하다고 느끼면, Luna로 버티기보다 재설정 시각을 보거나 재설정 횟수를 아껴 쓴다.
- 주간 한도가 남아 있어도 5시간 창이 0%면 고급 모델은 그 창이 끝날 때까지 못 쓴다.
- Work Agent 본업(문서·조사·정리)은 Luna로도 이어갈 수 있다. 다만 품질이 떨어지면 고급 모델 회복을 기다린다.
