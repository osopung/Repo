# 슈퍼 휴먼이 하는 일

## 1. AI에게 명확한 방향을 준다

AI는 무에서 유를 만드는 마법 지팡이가 아니라 **사용자의 명확함을 증폭하는 엔진**이다.

- 목표가 분명하면 빠르고 정확하게 결과를 만든다.
- 목표가 흐리면 혼란스러운 결과를 더 많이 만들어 낸다.
- AI의 성능보다 먼저 사용자의 미션이 선명해야 한다.

> **AI는 명확함의 거울이다.**

## 2. 좋은 프롬프트보다 좋은 미션을 먼저 만든다

문장이 길고 그럴듯하다고 좋은 지시가 되는 것은 아니다. 먼저 다음을 정한다.

1. 누구를 위한 것인가?
2. 그 사람이 겪는 가장 큰 문제는 무엇인가?
3. 무엇을 만들어 해결할 것인가?
4. 어떤 결과가 나오면 성공인가?

### 막연한 목표

> 좋은 기획서를 만들어 줘.

### 명확한 미션

> 시리즈 A 투자를 검토하는 심사역이 5분 안에 시장 확장성과 기술적 차별성을 이해할 수 있는 3페이지 요약문을 만들어 줘.

대상·문제·결과·성공 기준이 구체적일수록 AI의 결과도 뾰족해진다.

## 3. 미션을 세 단계로 구체화한다

- **혼란:** AI를 써야 한다는 생각만 있고 무엇을 할지 모르는 상태
- **방향:** 교육·마케팅·자동화처럼 관심 분야는 정했지만 대상과 문제가 추상적인 상태
- **미션:** 특정 대상, 구체적인 고통, 해결 방법, 성공 기준까지 정한 상태

AI가 강력하게 작동하는 지점은 세 번째 단계인 **미션**이다.

## 4. 완벽함보다 임팩트를 우선한다

AI 시대의 효율성은 한 결과물을 완벽하게 다듬는 것이 아니라, 빠르게 실행하고 실제 반응을 확인하는 데 있다.

```text
80점 결과물 제작
→ 실제 사용·시장 반응 확인
→ 가치 있는 결과물 개선
```

이는 대충 만들라는 뜻이 아니다. 작업자의 자기만족을 위한 마지막 완벽함보다, 고객의 문제를 실제로 해결하는 결과를 우선한다는 뜻이다.

## 5. 여러 분야의 핵심 개념을 연결한다

모든 분야의 전문가가 될 필요는 없다. API, 변수, 데이터베이스처럼 각 분야의 핵심 개념과 용어를 알면 AI에게 필요한 작업을 지시할 수 있다.

- API: 프로그램을 연결하는 통로
- 변수: 데이터를 담는 그릇
- 데이터베이스: 정보를 저장하는 공간

직접 코드 95%를 작성하는 것보다, 무엇이 가능하고 어떤 개념이 필요한지 아는 것이 중요하다.

## 6. 직업을 바꾸기보다 역할을 확장한다

AI는 기존 전문성을 버리고 새 직업으로 다시 시작하게 하는 도구가 아니다.

- 기획자 → 기획 + 프로토타입 제작
- 디자이너 → 디자인 + 웹 구현
- 작가 → 글쓰기 + 자동화 도구 제작
- 비개발자 → 도메인 지식 + AI 기반 시스템 설계

> **AI는 자신의 전문성에 새로운 영토를 더하는 동료다.**

## 7. 인간이 맡아야 할 3P

### Problem Definition — 문제 정의

세상의 불편과 결핍을 발견하고, 그중 어떤 문제를 풀지 정한다.

### Product Definition — 제품 정의

문제를 해결하기 위해 무엇을 만들지 결정한다.

- 앱인가?
- 웹사이트인가?
- 뉴스레터인가?
- 단순한 자동화인가?

### Prompting Strategy — 프롬프팅 전략

AI에게 대상·배경·제약·결과 형식·품질 기준을 구체적으로 전달한다.

```text
어떤 문제를 풀 것인가
→ 어떤 형태로 해결할 것인가
→ AI에게 어떻게 시킬 것인가
```

## 8. 슈퍼 휴먼의 핵심 역할

슈퍼 휴먼은 코드를 직접 많이 쓰는 사람이 아니다.

- 해결할 문제를 발견한다.
- 대상과 고통을 구체화한다.
- 제품의 형태와 우선순위를 정한다.
- AI에게 명확하게 지시한다.
- 빠르게 결과를 만들고 실제로 시험한다.
- 반응을 보고 개선한다.

## 오소풍님의 월배당 ETF 대시보드에 적용한 미션

> **10개 이하의 ETF를 보유한 개인 투자자가 복잡한 거래관리 없이, 현재 가격·수량·평균 매수가를 입력하고 평가액·비중·손익·배당 전망을 한눈에 파악하도록 돕는 원화 기준 현황판을 만든다.**

이 미션이 분명했기 때문에 계좌 관리와 거래 원장을 제외하고, 환율 기능을 제거하며, 화면을 단순하게 만들 수 있었다.

## 한 줄 원칙

> **슈퍼 휴먼은 AI에게 일을 시키는 사람이 아니라, 어떤 문제를 누구를 위해 어떤 방식으로 해결할지 정한 뒤 AI를 지휘하는 사람이다.**
