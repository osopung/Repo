# 사서 스킬 — 글 여백

> 채팅·노트·스크립트. 여백을 두고 문단을 끊는다.

## 내 한 줄

글을 보기 쉽게 여백을 충분히 두고 문단을 끊어 정리하라.

- [x] 감수

## 언제

매 턴. 편집장이 다시 말하지 않아도.

채팅 답 · 위키 노트 · 유튜브 스크립트 · daily · 로그.

Cursor는 `.cursor/skills/librarian-prose/SKILL.md` 로 자동 상기.

## 손순

1. 문단을 끊는다.

   한 덩어리로 붙이지 않는다. 숨이 바뀌면 빈 줄을 넣는다.

2. 번호는 띄우고, 번호 아래는 붙인다.

   번호와 번호 사이는 빈 줄. 번호 바로 아래 설명 ~3줄은 빈 줄 없이.

3. 표로 몰아쓰지 않는다.

   일목요연은 표가 아니라 여백이다. (레지스트리 moc 표는 예외.)

4. 스크립트는 타임스탬프마다 빈 줄.

   말은 그대로. 문단·소제목만 나눈다.

5. 한 문장 한 줄로 잘게 쪼개지 않는다.

   한 숨은 붙여 둔다.

## 하지 말 것

- 채팅에만 지키고 파일에는 안 지키기
