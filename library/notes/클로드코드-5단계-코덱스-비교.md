# 클로드 코드 5단계 · 코덱스 비교

## 영상의 핵 (기술 나열 아님)

채팅 AI(챗GPT·제미나이)는 **조언자**. 클로드 코드는 **컴퓨터 안에서 폴더를 열고 파일을 만들고 고치고 실행하는 직원**. 가르침은 신입 인수인계와 같고, 공식은 다섯이다.


| 단계    | 영상                                          | 한 줄              |
| ----- | ------------------------------------------- | ---------------- |
| 1 목표  | 넣을 것 → 나올 것을 한 문장                           | 「회의록 관리 좀」은 금지   |
| 2 설계서 | 무엇을·왜·어떤 순서로 · **사람 검토 지점** · **하면 안 되는 일** | 빈칸을 채우지 말 것      |
| 3 환경  | 폴더 · CLAUDE.md · 스킬 · 서브 에이전트               | 설계서를 받은 에이전트가 세팅 |
| 4 실행  | 실제 자료를 넣고 돌려 본 뒤 검토                         | 표가 나와도 끝이 아님     |
| 5 성장  | 결과만 고치지 말고 **에이전트 파일에도 반영**                 | 다음 달에는 원본만 갈아끼움  |


두 예시: 회의록 네 장을 한 표로 / 견적은 **조사(사실만) · 분석(계산) · 작성**을 나눈다. 한 명에게 셋 다 시키면 「싸 보이는 것」을 싸다고 결론낸다.

영상 스스로도 **100% 자동화는 아직 아니다**. 98% + 마지막 검토는 사람.

## 코덱스와 겹치는 것

집의 코덱스는 윈도우 공장의 **실행형 동료**다. 파일을 만들고 고치고, 코드를 돌리고, 화면을 확인한다. [[library/notes/코덱스-활용의-핵심-인사이트]] · [[library/notes/코덱스-역할]]


| 영상 (클로드 코드)           | 집 (코덱스 · 공장)                                   |
| --------------------- | ---------------------------------------------- |
| 조언자 vs 직원             | 고문 = 조언 · 코덱스 = 손발                             |
| 폴더 하나 = 업무 하나         | 공장 프로젝트 폴더. 집은 알되 본업은 Factory                  |
| 설계서 MD                | `AGENTS.md` · 지침 · 스킬                          |
| CLAUDE.md (매번 읽는 매뉴얼) | 공장 AGENTS · 집 [[library/ops/코덱스에게]]            |
| 스킬                    | [[library/skills]] · 공장 스킬                     |
| 큰일은 계획 후 실행           | 코덱스 인사이트 §6 · ETF 때 목적→설계→승인→구현                |
| 결과 검증                 | 브라우저에서 실제 화면                                   |
| 피드백으로 성장              | 문서가 다음 작업의 재료                                  |
| 사람은 관리자·멘토            | ★5 [[library/notes/역할-병렬-결정-Orca]] — 결정은 내가 한다 |


「채팅에서 설계를 다듬고, 코드 창에서 실행한다」는 집의 **고문 / 코덱스** 가름과 같다. 설계를 실행 창에서 처음부터 쓰지 말라는 말도, 큰일은 계획부터라는 집 규칙과 같다.

「하면 안 되는 일」세 줄(원본 고치지 마 · 없는 항목 만들지 마 · 없으면 비워 둬)은 ★5 [[library/notes/팬픽-빈칸을-채우는-글쓰기|빈칸을 채우는 글쓰기]]의 반대편이다. 에이전트가 세계를 그럴듯하게 메우면 환각이다. 집은 이미 그 위험을 안다.

## 다른 것 · 가져오면 안 되는 것

1. **도구를 갈아타라는 영상이 아니다.** 클로드 데스크톱·코드 탭은 그 채널의 세팅이다. 집의 손발은 이미 코덱스(공장)다. 같은 5단계를 클로드 코드로 한 벌 더 깔 필요는 없다.
2. **「모든 업무를 대신」은 과장이다.** 영상 본문도 98%까지만 말한다. 사서가 그 첫 문장을 사실로 쓰면 집을 빗나간다.
3. **코덱스는 사서 자리를 빼앗지 않는다.** 영상은 한 사람의 클로드 코드가 폴더 전체를 맡는다. 집은 레인이다 — 위키 소화는 사서, 공장은 코덱스, inbox는 문. (2026-09-05)
4. **서브 에이전트 셋**은 공장 한 작업 안에서 역할을 나누는 법에 가깝다. 사서·헤르메스·고문·코덱스를 그 세 명으로 접지 말 것. 자리는 이미 나뉘어 있다.
5. 이 영상에 대한 **코덱스 본인 정리문은 집에 없다.** 비교 대상은 코덱스 지침·인사이트·역할 노트다. 코덱스가 같은 링크를 따로 소화한 파일이 있으면 inbox에 주시면 그다음 대조가 정확해진다.



## 사서 인사이트

가져올 핵은 하나다. ==**결과물을 고친 뒤 「에이전트 파일에도 반영해 줘」를 붙이는 습관.==** 코덱스도 결과만 고치고 공장 `AGENTS.md`·스킬을 안 고치면, 다음번에 같은 일을 또 시킨다. 영상 5단계의 5번이 집에 가장 얇다.

회의록·견적 예시는 Studio 본업이 아니다. 다만 **형식 다른 원본을 한 줄로 세우는 일**(스캔·편지·운영내력)에는 같은 뼈가 있다.

**적용 자리 (2026-09-12 편집장):** 한 앱이 아니라 **Factory 폴더 전체** — 공장 루트 `AGENTS.md`. 집 사본 [[오소풍 AI Studio/02-Factory/공용-작업-규칙]] · 코덱스 지침 [[library/ops/코덱스에게]].
