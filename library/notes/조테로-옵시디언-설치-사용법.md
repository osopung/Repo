# ==조테로 × 옵시디언 — 설치·사용법 ★공부

> **목적:** 조테로를 옵시디언(오소풍_wiki)에 연동하기 위해 **설치부터 일상 사용까지** 한곳에서 숙지.  
> 근거: 브레인 트리니티 영상·스크립트 + Drive 메모. 에이전트는 Cursor 사서 (Claude Code 대체 OK).

## 내 한 줄

조테로는 검증한 서재, 옵시디언은 사서 — 설치는 Zotero→커넥터→ZotMoov·Better BibTeX→Integration·Templater 순.

## 왜 연동하나 (한 장)

- 출처·메타데이터가 위키로 들어와 **인용·환각 방지**
- PDF 하이라이트·메모가 노트로 들어와 **수집→==글쓰기 선순환**

## 일상 사용법 (최소 루프)

1. **수집** — 브라우저에서 Connector로 Zotero에 담기 · 컬렉션·태그  
2. **읽기** — Zotero PDF에서 하이라이트·코멘트 (신호등: 빨강=핵심, 노랑=천천히, 초록=배경)  
3. **가져오기** — Obsidian **Zotero Integration**으로 해당 항목만 노트 생성  
4. **소화** — `## 내 한 줄` · `## 연결` · 필요 시 사서와 요약·백링크  
5. **창작** — essays/art로 승격은 편집장 판단  

대용량 PDF·원본은 볼트에 넣지 않는다 → ★5 [[library/notes/오소풍-공유폴더|오소풍-공유폴더]] / `오소풍-미디어-보관`.
