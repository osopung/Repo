# ChatGPT 대화를 Zotero로 보관하는 방법

## 내 한 줄

(초안) 대화 전체를 매번 옮기기보다, 최종 대화를 Zotero에 한 번 보관하고 필요한 문장만 선별한다.

- [ ] 감수

## 확인한 방법

ChatGPT 대화 페이지에서 **Zotero Connector**를 누르면 현재 화면의 대화 전체가 Zotero에 저장된다.

- 새로 추가된 부분만 저장되는 것이 아니다.
- 기존 대화에 자동으로 덧붙여지는 것도 아니다.
- Connector를 다시 누르면 그 시점의 전체 대화가 별도 항목으로 저장된다.
- 따라서 같은 대화를 반복 저장하면 중복 항목이 생긴다.

## 권장 흐름

```text
ChatGPT 대화
→ 주제별 대화가 끝날 때까지 진행
→ 최종본에서 Zotero Connector 한 번 클릭
→ Zotero에서 원본 보관
→ 필요한 문장만 형광·주석
→ 선별한 액기스만 NotebookLM 또는 LLM 위키로 이동
```

## 자동화 원칙

- 수집과 보관은 자동화한다.
- 반복 저장으로 중복 자료를 만들지 않는다.
- 무엇을 중요한 문장으로 남길지는 직접 선택한다.
- Zotero에는 원본 대화를 보관하고, 위키에는 선별한 생각만 기록한다.

> **Zotero는 대화 원본을 보관하는 서고이고, 위키는 그 대화에서 건진 생각을 남기는 곳이다.**
