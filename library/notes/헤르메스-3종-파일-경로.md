## 내 한 줄

(초안) 헤르메스의 헌법(SOUL)·기억(MEMORY)·사용자(USER)는 호스팅어 VPS `/opt/data/` 안에 있고 **GitHub가 아니다.** Git으로 오가는 것은 그 안의 `Repo/`(위키 clone)뿐이며, 3종 파일을 고치는 길은 텔레그램 지시 · 대시보드 · SSH 셋뿐이다.

```text
Hostinger VPS  (srv1886227.hstgr.cloud — 헤르메스가 사는 서버)

    ├── memories/

    │   └── USER.md               ← 사용자 성향 · Git 아님 · GitHub에 없음

        ├── inbox/                ← 헤르메스가 위키에 쓸 수 있는 유일한 곳
        ├── library/
        └── …
```

## 3종 파일

| 파일 | 전체 경로 | 역할 | Git |
|---|---|---|---|
| SOUL.md | `/opt/data/SOUL.md` | 헌법 — 정체성 · 하지 말 것 | ✕ |
| MEMORY.md | `/opt/data/memories/MEMORY.md` | 업무 기억 | ✕ |

## 사서 인사이트 (초안)

집(Git)과 본체를 가르는 선이 `/opt/data/Repo`의 경계다. 헌법·기억이 Git 밖이라는 뜻은 — 위키가 아무리 두꺼워도 헤르메스의 됨됨이는 이 세 파일이 결정한다는 것. 반대로 위키는 헤르메스 본체가 죽어도 남는 도서관이다.
