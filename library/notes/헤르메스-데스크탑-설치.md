## 내 한 줄

(초안) **데스크탑은 헤르메스의 창일 뿐, 24시간 본체는 여전히 VPS다.**

- [ ] 감수

## 한 줄 정의

Hermes Desktop은 터미널이 아니라 **창으로 같은 에이전트**를 쓰는 공식 GUI다. CLI·텔레그램·웹 대시보드와 설정·세션·스킬·기억을 공유한다. 별도 제품이 아니다.

## 자리 (오소풍)

| 역할 | 어디 |
|------|------|
| **본체(24시간)** | Hostinger VPS · Telegram |
| **데스크탑 GUI** | 맥(또는 이 클라우드 데스크탑)에서 창으로 부르기 — **선택** |
| **사서** | 맥 Cursor · 위키 논지·감수 |

VPS를 맥 설치로 바꾸지 않는다. 데스크탑은 **입구**다.

## 맥에 설치 (권장)

1. [Installation](https://hermes-agent.nousresearch.com/docs/getting-started/installation)에서 **Hermes Desktop installer** 받기 (macOS · Windows)
2. 설치 후 앱 실행 → 첫 화면에서 프로바이더를 고르거나 **Choose provider later**
3. 이미 CLI가 있으면 터미널에서 `hermes desktop`

공식: [Desktop App](https://hermes-agent.nousresearch.com/docs/user-guide/desktop)

## 리눅스 (터미널)

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash -s -- --include-desktop --non-interactive --skip-setup
```

끝나면 `source ~/.bashrc` 후 `hermes desktop`.

전제: Git · curl · xz-utils. 데스크탑 빌드는 `build-essential`(g++). Node는 설치기가 **26**을 넣는다 (시스템 Node 22는 부족).

## 이 세션에서 한 일 (2026-08-23)

Cursor 클라우드 리눅스 데스크탑(`DISPLAY=:1`)에 위 리눅스 경로로 설치 완료.

- Hermes Agent **v0.20.5** (2026.8.19)
- 앱 바이너리: `~/.hermes/hermes-agent/apps/desktop/release/linux-unpacked/Hermes`
- 실행: `hermes desktop --skip-build` 또는 런처 **Hermes Agent**
- `--skip-computer-use` — cua-driver는 나중에 `hermes computer-use install`
- 설치 마법사 생략 → 모델·키는 앱 **Settings → Model** 또는 `hermes setup` / VPS 원격 연결
- 브라우저 도구(Playwright Chromium)는 설치 중 일부만 내려받음 · `hermes doctor`에 browser 경고 남을 수 있음

## VPS에 창을 붙이려면 (제안)

본체는 Hostinger에 있다. 로컬에 두뇌를 하나 더 두지 않으려면:

1. VPS에서 `hermes serve`가 떠 있어야 함 (텔레그램 게이트웨이와는 별 프로세스)
2. 데스크탑 **Settings → Gateways → Remote gateway**에 VPS URL
3. 공개망이면 **Nous Portal OAuth**. 비밀번호만으로 인터넷에 열지 말 것 (Tailscale 권장)

연결은 편집장이 VPS 주소·인증을 열 때. 사서가 추측으로 붙이지 않는다.

## 쓰지 않는 것

- 데스크탑이 위키 `library/`·`오소풍.md`를 직접 고치지 않음 — inbox만 ([[inbox/헤르메스에게]])
- Drive OAuth를 VPS/로컬 헤르메스에 붙이지 않음 — 사서가 한다
- 맥에 본체를 올려 24시간 돌리기 — 이미 VPS로 확정
