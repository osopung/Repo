# 헤르메스가 코덱스 토큰쓰기 ★5

> 검색: **5스타** · **5\*** · 헤르메스 · 코덱스  
> 확인: Hostinger 안내 2026-08-13 · Hermes 공식 Providers (2026-09-04 조회)

## 내 한 줄

(초안) 호스팅어 아이디는 나누지 않는다. 헤르메스가 코덱스 전기를 쓰려면 hPanel에서 챗GPT Plus/Pro를 연결하면 된다. 위키와는 다른 줄이다.

- [ ] 감수

## 무엇을 나누나

사서 말 「아이디를 나누면」은 **호스팅어 로그인을 둘로 쪼개라**가 아니었다. 공식도 그렇게 시키지 않는다.

| 줄 | 나누나 | 이유 |
|--|--|--|
| **호스팅어 계정** | **아니요** | 본체 하나. 그대로 둔다 |
| **위키 Git** | **아니요** | 이 연결과 무관. inbox 규칙 그대로 |
| **챗GPT 계정** | **기본은 아니요** | Plus/Pro가 있는 그 계정으로 연결한다 |
| **챗GPT를 둘로** | **선택** | 공장과 밤 학습의 **한도를 가르고 싶을 때만** |

윈도우 코덱스와 호스팅어 헤르메스는 로그인 저장 위치가 다르다. Hermes는 `~/.hermes/auth.json`, 코덱스 CLI는 `~/.codex/auth.json`. 공식은 둘을 일부러 안 섞는다. 같은 챗GPT라도 **기기마다 한 번씩** 인증하면 된다. 한도를 나누려면 계정을 둘로 사는 것이고, 호스팅어를 둘로 만드는 일이 아니다.

## 공식 연결 (hPanel)

Hostinger: [How to use your ChatGPT subscription in Managed Hermes](https://www.hostinger.com/support/how-to-use-your-chatgpt-subscription-in-managed-hermes/)

필요: Managed Hermes가 **온라인** · **챗GPT Plus 또는 Pro**.

1. hPanel → **Hermes** → 앱 **Manage**
2. **AI provider** → **OpenAI**
3. **Use your ChatGPT subscription** → **Connect**
4. 이미 OpenAI API 키가 있으면 전환을 확인한다. 확인하면 **그 API 키는 지워진다.** 구독과 API 키는 **둘 중 하나**다.
5. 안내 링크로 가서 Plus/Pro 계정으로 로그인 → 코드를 hPanel에 붙여 **Verify**
6. 앱이 재시작된다. **Connected**가 뜨면 연결된 것이다.

Connect가 회색이면 앱이 꺼져 있다. 카드가 안 보이면 앱 버전이 낮다. 업데이트 후 다시.

nexos.ai 크레딧(지금 Luna)은 **다른 탭**이다. OpenAI 구독을 켜면 그 길의 전기는 챗GPT 월정액이다. 종량제 OpenAI 키가 아니다. ★5 [[library/notes/글쓰기-Claude-비용-Pro-vs-API|Pro ≠ API]]와 같다.

## 무엇이 닳나

Hermes 공식: 제공자 이름은 **OpenAI Codex**. `hermes model` → ChatGPT or Codex Subscription. 기기 코드로 로그인. 코덱스 CLI를 깔 필요는 없다.

다만 **어느 플랜 한도가 얼마나 깎이는지**는 공식 문서가 아직 안 적었다. 연결되면 Nexos 미터는 그 길에서 멈춘다. 남은 걱정은 **챗GPT/코덱스 구독 한도**다. 공장 윈도우와 **같은 계정이면 한 그릇**이다.

## 집이 건드리지 않는 것

- 위키 `osopung/Repo` · inbox 규칙
- 공장 `osopung/Factory` Git
- 호스팅어 계정 분리

전기만 바꾼다. 손(누가 Git을 여나)은 그대로다.

## 사서 인사이트 (초안)

「호스팅어 아이디 나누기」로 기억하면 틀린다. 나눌 후보는 **챗GPT 한도**뿐이고, 기본은 **같은 Plus/Pro로 연결**이다.
