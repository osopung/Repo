# ChatGPT 모델 한도와 Luna

## 내 한 줄

(초안) 고급 모델을 다 쓰면 채팅이 멈추는 게 아니라 가벼운 **Luna**로 바뀐다 — 기다리거나, 재설정을 쓰거나, 플랜·크레딧으로 연다.

- [ ] 감수

## 핵심

- **5시간 한도**(짧은 창)와 **주간 한도**는 따로 — 5시간 창이 0%면 주간이 남아도 고급 모델 불가. (그날 본 값: 5시간 0% 남음·16:44 재설정 / 주간 78% 남음)
- **사용 한도 재설정** — 기다리지 않고 지금 고급 모델을 여는 횟수. 유한하다.
- **Luna Reserve** — 고급 모델이 막혀도 이어 쓸 수 있는 가벼운 모델.
- 막혔을 때: ① Luna로 이어가기 ② 재설정 시각까지 기다리기 ③ 재설정 1회 쓰기 ④ 플랜 업그레이드·크레딧.
- Work Agent 본업(문서·조사·정리)은 Luna로도 이어갈 수 있으나 품질이 떨어지면 회복을 기다린다.

## 같은 이름, 다른 몸

- ChatGPT의 **Luna** = 고급 모델 한도가 떨어졌을 때 켜지는 가벼운 대체 모델.
- 집의 헤르메스 **Luna** = VPS 쪽 메인 모델(Nexos). 이름만 같다.

## 사서 인사이트 (초안)

고문이 Work Agent 화면의 「사용량」 팝업을 읽고 정리한 실무 쪽지다. 「Luna」가 두 자리에서 쓰이니 이 노트가 헷갈림 방지선이 된다. 5시간 창의 존재는 「긴 작업은 창이 열려 있을 때」라는 시간 감각을 요구한다.
