# 크론잡과 학습루프 ★5

> 검색: **5스타** · **5** · 크론잡 · 학습루프 (`학습루푸`로 찾아도 여기)  
> 출처: 2026-09-04 김효율 영상 공부 · [[_archive/youtube-에이전트-학습-천재적-방법-스크립트|스크립트]]

## 내 한 줄

학습루프는 시킨 방식을 스킬로 남기는 것과 어떤 특별한 분야 공부가 될 수도 있고, 크론잡은 그 스킬과 공부를 시각에 맞춰 다시 실행하는 것이다.

- [x] 감수

## 둘은 한 세트

영상 말 「크론잡이라는 예약 작업 기능과 학습 루프 기능」.


|          | 무엇인가                              | 아닌가               |
| -------- | --------------------------------- | ----------------- |
| **학습루프** | 한 번 시킨 일·형식·금지를 `/learn`으로 스킬에 고정 | 논문을 메모리에 밤새 붓기    |
| **크론잡**  | 그 스킬을 정해진 시각에 다시 실행               | 스킬 파일을 복제. 캘린더 반복 |


수순은 이미 있다. ★5 [[library/notes/스킬-먼저-Cron|스킬 먼저, 그다음 Cron]]

1. 손으로 몇 번 시킨다.
2. 손순이 같으면 스킬로 남긴다 (`/learn`).
3. 안정되면 **같은 스킬**을 크론에 건다.
4. 다른 일이 반복되면 그때 새 스킬.

## `/learn` 하는 법

텔레그램·대시보드 어디서나. 한 줄이다.

```text
/learn (무엇으로 스킬을 만들지)
```

공식 예:

```text
/learn 방금 스테이징 서버를 배포한 그 방식
/learn https://docs.example.com/api/quickstart
/learn 경비 청구: 포털 열기 → New > Expense → 영수증 → 제출
```

집 예 — 문지방 재료를 한 번 시켜 초안이 괜찮으면, 같은 방에서:

```text
/learn 방금 한 문지방 재료. 목적·자료·형식·금지·초안만 보여 주기. inbox는 넣으라고 할 때만.
```

헤르메스가 `SKILL.md`를 만든다. 쓰기 승인이 켜져 있으면 저장 전에 묻는다. 다음부터는 `/문지방-재료`처럼 슬래시로 다시 부른다.

대시보드: **Skills → Learn a skill** (폴더·URL·설명).

공식: [Skills System — /learn](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills)

`/learn`만 치면 안 된다. **무엇을 배울지**를 붙인다. 결과물은 위키가 아니라 헤르메스 안 스킬이다. 집 notes로 옮기는 일은 사서가 ingest할 때다.

## 집 한 바퀴 (문지방)

**1. 낮에 손으로** — [[library/skills/헤르메스-지시스킬|지시스킬]] 공식.

```text
목적: 문지방 초고에 쓸 짧은 재료.
자료: 오늘 내가 말한 한 줄만. 위키 notes는 열지 마.
형식: 출처 둘, 메모 다섯 줄. 추측 금지.
금지: inbox에 바로 넣지 마.
실행: 초안만 보여 줘.
```

**2. 학습루프** — 초안이 괜찮으면 `/learn`으로 남긴다. 이틀 더 같은 말로 시킨다.

**3. 크론잡** — 흔들리지 않으면:

```text
매일 23:30, 스킬 「문지방 재료」를 실행.
결과는 텔레그램으로 보내. inbox는 「넣어라」고 할 때만.
```

아침 다섯 줄을 고치고, 사서가 집에 넣는다. MEMORY에는 키워드만. 본문은 위키. 자료를 기억에 다 넣으면 에이전트가 멍청해진다 (영상).

캘린더 「글쓰기 09–12」는 사람의 뼈대다. 헤르메스 실행이 아니다. 실행은 VPS 크론이다.

## 영상 ↔ 집


| 영상            | 집                    |
| ------------- | -------------------- |
| 자는 시간에 논문·드리블 | 23:30 **문지방 재료 스킬**  |
| 학습 루프         | `/learn` · 목적·형식·금지  |
| 크론잡           | 그 스킬을 그 시각에 실행       |
| 위키화           | 아침 inbox → 사서 ingest |


지금은 Luna. 밤은 **짧은 한 장**. Nexos가 거의 바닥이면 챗GPT 머리로 같은 스킬. ★5 [[library/notes/헤르메스가-코덱스-토큰쓰기|헤르메스가 코덱스 토큰쓰기]]

헤르메스는 초상은 알아도, 글·캘리의 손맛(도메인 지식)은 스킬·위키로 가르친다.

## 사서 인사이트

크론만 먼저 걸면 실패가 종량제로 반복된다. `/learn`만 쌓고 안 돌리면 훈련이 안 된다. 둘을 한 주제로 묶는다.
