## 내 한 줄

(초안) Smart Composer는 지금 연 노트의 문장을 다듬는 도구, Cursor 사서는 위키 전체를 도는 도구.

- [ ] 감수

## 여는 법

1. 왼쪽 리본 또는 Command Palette(`Cmd+P`)에서 **Smart Composer** / **Open chat**
2. 단축키는 Settings → Hotkeys에서 `Smart Composer`로 확인

## 쓰는 법

1. 채팅창에 질문·지시 입력
2. 노트 맥락이 필요하면 `@`로 파일·폴더 지정 (예: `@옵시디언-지식-꺼내쓰기-구요한` 요약해 줘)
3. AI가 제안한 문장은 **Apply**로 노트에 반영

### 잘 쓰는 예 (오소풍)

- "이 노트 `## 내 한 줄` 초안만 다듬어 줘" (`@`해당 노트)
- "`@purpose`랑 `@기록하는-인간` 이어서 에세이 한 단락"
- 웹·유튜브 링크를 붙여 맥락으로 쓰기 (지원되면 자동 추출)

### 기억할 것

- 모델/Google 연동은 Settings → Smart Composer
- Cursor 사서처럼 inbox·daily·log를 자동으로 돌리지는 **않음** — 지금 연 노트 초안·문장용
