## 내 한 줄

헤르메스 본체는 **클라우드 VPS**에 두고, 아이폰은 텔레그램으로만 부른다. Drive·위키 깊은 일은 사서, 상시·폰은 헤르메스.

- [x] 감수

## 구조 (편집장 선택 · 2026-08-07)

| 역할 | 어디 |
|------|------|
| **Hermes 본체(서버)** | **클라우드 VPS** (상주) |
| **아이폰** | 텔레그램 앱으로 대화 |
| **맥** | 설치 안 해도 됨 · SSH로 서버만 관리하면 됨 |

이전에 「맥 설치」라고 적은 것은 **한 가지 선택지**였을 뿐.  
편집장 방침: **서버 = 클라우드**.

## 오늘 순서 (클라우드)

1. **VPS 준비** — Ubuntu 등 작은 인스턴스 (가성비 ≈ 월 $5~10대) · SSH 접속
2. **서버에 Hermes 설치**  
   `curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash`
3. **모델/프로바이더** — `hermes setup` (또는 `--portal` / `hermes model`)  
   - 무료 Gemini 티어는 에이전트에 약함 → 유료 API·저가 모델 권장
4. **텔레그램**  
   - BotFather → 봇 토큰 · 내 numeric user id  
   - `hermes gateway setup` → Telegram  
   - `hermes gateway install` (서버에서 부팅 후에도 상주)
5. **아이폰 텔레그램**에서 봇에게 메시지 → 의도·메모 시험

## 목적 (오소풍)

- **24시간 그림자 개인비서** — 의도·계획·메모·곁에서 돕기  
- Cursor 사서·옵시디언과 역할 분리 (헤르메스 = 상주 비서 · 사서 = 위키·기록·감수)

## 역할 분담 (반드시)

- 너(헤르메스): 폰·일상·상시 실행 · Cron 예약 · inbox에 짧은 기록 쌓기
- Cursor 사서: 위키 논지·감수·정리 · Google Drive / Calendar / Gmail 깊은 작업
- 너는 위키의 편집장 노릇을 하지 않는다. 필요할 때 「위키/사서에 넘기자」고 제안만 한다.
- Google Drive·Photos에 VPS에서 OAuth로 직접 붙지 말 것. Drive/일정이 필요하면 사서 쪽을 안내한다.
- 구글포토·드라이브 원본을 볼트에 통째로 복사하지 말 것. 원본은 포토/드라이브에, 작업용은 선별된 소수·링크만.

## 위키 쓰기 (A안)
