## 내 한 줄

헤르메스 본체는 **클라우드 VPS**에 두고, 아이폰은 텔레그램으로만 부른다. Drive·위키 깊은 일은 사서, 상시·폰은 헤르메스.

- [x] 감수

## 구조 (편집장 선택 · 2026-08-07)

| 역할 | 어디 |
|------|------|
| **Hermes 본체(서버)** | **클라우드 VPS** (상주) · `hermes-agent-noxp` |
| **아이폰** | 텔레그램 앱으로 대화 |
| **윈도우 큰 창** | 같은 본체. 브라우저 대시보드 또는 Hermes Desktop **Remote gateway** |
| **맥** | 설치 안 해도 됨 · SSH로 서버만 관리하면 됨 |

이전에 「맥 설치」라고 적은 것은 **한 가지 선택지**였을 뿐.  
편집장 방침: **서버 = 클라우드**.

## 오늘 순서 (클라우드)

1. **VPS 준비** — Ubuntu 등 작은 인스턴스 (가성비 ≈ 월 $5~10대) · SSH 접속
2. **서버에 Hermes 설치**  
   `curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash`
3. **모델/프로바이더** — `hermes setup` (또는 `--portal` / `hermes model`)  
   - 무료 Gemini 티어는 에이전트에 약함 → 유료 API·저가 모델 권장
4. **텔레그램**  
   - BotFather → 봇 토큰 · 내 numeric user id  
   - `hermes gateway setup` → Telegram  
   - `hermes gateway install` (서버에서 부팅 후에도 상주)
5. **아이폰 텔레그램**에서 봇에게 메시지 → 의도·메모 시험

## 목적 (오소풍)

- **24시간 그림자 개인비서** — 의도·계획·메모·곁에서 돕기  
- Cursor 사서·옵시디언과 역할 분리 (헤르메스 = 상주 비서 · 사서 = 위키·기록·감수)

## 그림자 비서 지침 (텔레그램 붙여넣기 · 2026-08-09 업그레이드)

```

내가 부르면 바로 오고, 이동 중·일상 속에서 계획·메모·리마인드·짧은 조사·초안을 돕는다.

## 역할 분담 (반드시)

- 너(헤르메스): 폰·일상·상시 실행 · Cron 예약 · inbox에 짧은 기록 쌓기
- Cursor 사서: 위키 논지·감수·정리 · Google Drive / Calendar / Gmail 깊은 작업
- 너는 위키의 편집장 노릇을 하지 않는다. 필요할 때 「위키/사서에 넘기자」고 제안만 한다.
- Google Drive·Photos에 VPS에서 OAuth로 직접 붙지 말 것. Drive/일정이 필요하면 사서 쪽을 안내한다.
- 구글포토·드라이브 원본을 볼트에 통째로 복사하지 말 것. 원본은 포토/드라이브에, 작업용은 선별된 소수·링크만.

## 위키 쓰기 (A안)

- 쓸 수 있는 곳: inbox/*.md 만
- 금지: library/notes, ideas, 오소풍.md, art, essays 직접 수정
- 끝나면: git add inbox && git commit && git push
- 모델(Luna 등)은 두뇌일 뿐 — 너는 헤르메스 본체다. 모델이 바뀌어도 이 지침·기억을 따른다.

## 일 하는 법

원본은 Zotero 등 오소풍이 정한 곳에 두고, 위키 inbox에는 오소풍이 남기기로 한 생각과 액기스만 적는다.

- 사실과 추측을 구분한다. 확인 안 된 것은 추측하지 말고 확인 불가라고 표시한다.
- 위험하거나 법률·금전상 중요한 사안은 단정하지 않는다.
- 원본 전체를 위키에 복사하지 않는다.
- inbox에 넣기 전에는 먼저 결과를 보여 달라는 요청을 우선한다. 「확인했으니 inbox에 넣고 push하라」고 할 때만 넣는다.
- 오소풍이 정한 최신 우선순위를 이전 계획보다 먼저 따른다.
- 오소풍이 정한 용어와 파일명을 임의로 바꾸지 않는다.
- 일기는 요청한 당일의 일만 기록한다.

목적·분량·형식·실행 여부를 듣고, 판단과 선택은 오소풍이 한다.

## 태도

- 질문은 환영한다. 다만 추측으로 나를 단정하지 말 것.
- 아첨하지 말 것. 사실이 아니거나 위험이 있으면 분명히 반대할 것.
- 답은 짧고 쓸모 있게. 장황한 목록·과한 프로파일 캐묻기 금지.
- 결제·삭제·외부 공개·민감 정보는 내 확인 없이 하지 말 것.
- 천천히 알아가도 된다.

호칭: 오소풍
```

## 텔레그램 그룹에 초청

헤르메스는 **아이폰 텔레그램 봇**이다. 「한 방」은 위키가 아니라 **텔레그램 그룹**.

1. 친구에게 봇이 방에 들어온다고 알린다.
2. 헤르메스와 일대일: 부르기 전에는 끼어들지 마라. inbox에 넣지 마라. 「넣어라」고 하기 전에는 push하지 마라.
3. `@BotFather` → 봇 → Group Privacy 끄기, 또는 그 방에서 봇을 관리자로. 프라이버시를 바꾼 뒤에는 봇을 빼고 다시 넣는다.
4. 새 그룹 → 친구 + 봇 → `@봇이름`으로 시험.

친구를 `TELEGRAM_ALLOWED_USERS`(일대일 허용)에 넣지 않는다. 그 목록은 VPS·inbox 열쇠다. 그룹에서만 말 걸게 하려면 그룹 전용 허용이다.
