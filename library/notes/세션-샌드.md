# 세션 샌드 ★5

> 검색: **5스타** · **5\*** · 세션 샌드 · `session send` · 보이는 넘김  
> 출처: 2026-09-04 김효율 영상 공부 · [[_archive/youtube-에이전트-학습-천재적-방법-스크립트|스크립트]]

## 내 한 줄

(초안) 세션 샌드는 에이전트끼리 일을 넘기는 것이다. 집에선 숨기지 않고, 누구에게·무엇을·어디에 두었나를 남긴다.

- [ ] 감수

## 영상 말

자막은 **세션 샌드**. 영어는 **session send**.

시원에게 「다른 에이전트들한테 이거 시켜」라고 하면, 눈에는 안 보이지만 에이전트끼리 지시·보고하고, 시원이 사람에게 최종 보고한다.

협력 자체가 문제는 아니다. 안 보이는 넘김이 문제다.

김효율도 헤르메스와 클로드를 한 방에 안 넣는다. 「방해」를 **여러 요청으로 혼선**이라고 풀었다. 맥락은 위키로 나눈다.

## 집

| | 보이는 넘김 | 안 보이는 넘김 |
|--|--|--|
| **누구에게** | 사서 / 헤르메스 / 고문 / 코덱스 중 **하나** | 「저쪽에 시켜」 |
| **무엇을** | 일 하나 | 알아서 분기 |
| **어디에** | inbox · 공장 산출물 · 채팅 보고 · Git 커밋 | 세션 안에서만 |

최소 문장:

```text
헤르메스 → 사서. inbox/문지방-재료.md push함. 초안만. inbox에 넣지 말라고 했음.
```

집이 이미 쓰는 수순:

1. 헤르메스·고문이 `inbox/`에 쓰고 push한다.
2. 편집장(또는 헤르메스)이 사서에게 **push 됐다**고 알린다.
3. 사서가 pull하고, **파일 경로·커밋 한 줄**을 채팅에 올린다.
4. 그다음 ingest. 결정은 편집장.

코덱스는 공장에서 만들고, 집에 넣을 글은 **편집장이 사서에게** 전한다. 책상을 갈라 동시에 돌려도 된다. ★5 [[역할-병렬-결정-Orca|역할 · 병렬 · 결정]]

세 곳에 같은 한 일이 보이면 된다. 텔레그램 · 이 Cursor 채팅 · `inbox/`.

## 사서 인사이트 (초안)

에이전트는 기본이 동료가 아니라 각자 사장이다. 같은 집을 두 사장이 고치면 Git이 갈라진다. 위키와 inbox는 우체통이지, 몰래 시키는 전선이 아니다.
