# Claude · 비용 — Pro vs API ★5

> 검색: **5스타** · **5\*** · Claude · Pro  
> (자판에 ★ 없어도 `5*` 또는 `5스타`로 찾기)

## 내 한 줄

Pro = 웹 이용권, API = 도구에 꽂는 전기. 이름만 Claude로 alike하지, 한도·키가 공유되지 않는다.

- [x] 감수

## 한 줄로 (핵심)

- **Pro = 웹·앱 이용권만.**
- **API 키·종량제 크레딧은 그 안에 없다.**
- Pro = 웹 이용권, API = 도구에 꽂는 전기. 이름만 Claude로 alike하지, 한도·키가 공유되지 않는다.

| 하고 싶은 일 | 필요한 것 |
|--------------|-----------|
| 웹에서 글쓰기 | Pro(또는 무료)만 |
| Smart Composer에서 Claude | API만 (Pro 없어도 됨) |
| 둘 다 | Pro + API **둘 다** 돈 |

## 교훈

헤르메스 크레딧 초과 경험 → **종량제(API·크레딧)는 방심하면 튀었다.**  
적게 쓸 때만 「API가 Pro보다 싸다」가 맞다.

## Pro vs API

| | Pro (claude.ai) | API |
|--|-----------------|-----|
| 돈 | 냄 (월 고정) | 냄 (쓴 만큼) |
| 체감 | 한도 안에서 쓰기 | 긴 글·반복 퇴고 시 순식간에 튐 |
| Smart Composer | Pro만으로 안 열림 | 키 넣으면 Composer에서 Claude 가능 |
| 겹침 | 웹 전용 | Composer·헤르메스에 붙이면 **또** 지출 |

둘 다 유료다. 차이는 공짜가 아니라 **고정 vs 종량**.

Pro 한도(참고): 세션 약 5시간 리셋 + **주간** 한도. 「매일 API가 다시 생기는」 구조가 아님. (`설정 → Usage`)

## 오소풍 조합 (지갑)

1. **일상·비서** — 헤르메스: Luna 등 싼 모델. Claude를 기본으로 두지 않음.  
2. **옵시디언 짧은 작업** — Smart Composer: **Gemini** 유지.  
3. **글쓰기 Claude** — 자주·장문 → **Pro 웹** → 위키로 가져오기.  
   가끔만 → API 가능하되 Console **월 한도·알림** 필수.  
4. Composer·헤르메스에 Claude API **상시 연결 비추** (이중·초과 위험).
