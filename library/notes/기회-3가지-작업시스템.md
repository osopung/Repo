# 기회 3가지 — 개인 작업 시스템

## 내 한 줄

작업 흐름 대시보드 · 지식 저장소의 운영 매뉴얼화 => 프로젝트 진행 템플릿으로, 측정 지표 1개 weekly에 얹자

- [x] 감수

## 핵심

- 진단: 최근 흐름은 ==「AI를 실제 작업 완료까지 연결하는 개인 작업 시스템」 ==— Hermes 대시보드 운영 · Git `inbox → 검수·보관` 정착 · 윈도우 동기화 해결.
- **기회 1** — 작업 흐름을 하나의 대시보드로 (진행 중 / 검수 대기 / 완료).
- **기회 2** — ETF 대시보드를 첫 완결형 MVP로 (CSV 입력 → 보유·배당 계산 → 월간 보고서).
- **기회 3** — ==지식 저장소를 실행 가능한 운영 매뉴얼로: 프로젝트마다 「목표 · 현재 상태 · 다음 행동 · 완료 기준」 고정.
- ==빈 곳: 정량 KPI가 없다. 주당 「완료물 1 · 우선순위 1 · 측정 지표 1」만 남겨도 선명해진다.
- 참조 Drive 문서 4건(Hermes 운영 기록 · 주간 메모 · ETF MVP 계획 · 바이브코딩 원칙)은 원본에 링크 있음.

## 사서 인사이트

기회 3은 이 집에 이미 씨앗이 있다 — 프로젝트 노트와 감수 제도가 「목표·상태·다음·완료 기준」을 사는 자리다. 다만 ==「측정 지표 1개」==는 집에 없는 습관이다. weekly에 얹을지는 편집장 결정. (기회 2는 [[library/notes/첫-작품을-살아있는-도구로]]에서 챗지피티 스스로 정정 — ETF MVP는 이미 공장에 있다.)
