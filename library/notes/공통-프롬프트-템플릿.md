# 공통 프롬프트 템플릿 — 자료 검색 · 대화록 · 작품 기록

> [[library/notes/AI-에이전트-프롬프트-핵심-인사이트]]와 [[library/notes/프롬프트]]의 「다음」을 완성한 노트.

## 내 한 줄

(초안) 여섯 칸 — 목적·자료·형식·금지사항·검증 기준·실행 여부 — 을 채우면 자료 검색이든 대화록이든 작품 기록이든 같은 모양의 지시서가 된다.

- [ ] 감수

## 공통 뼈대 (여섯 칸)

```text
목적 — 이 일로 무엇을 얻는가 (한 문장)
자료 — 무엇을 보고 만드는가 (원문 · 범위 · 출처)
형식 — 결과물의 모양 (구조 · 분량 · 어디에 두는가)
금지사항 — 하지 말 것
검증 기준 — 완성을 스스로 확인하는 방법
실행 여부 — 바로 실행 / 초안 먼저 · 승인 후 실행
```

## 적용 1 — 자료 검색 (헤르메스 · 매일 07:00)

```text
목적: 오늘 적용할 한 가지를 고를 재료 10개를 찾는다 (AI 4 · 다큐 3 · 캘리 3)
자료: 웹 검색 — 최근 1년 · 최신순 · 한글 우선 (영문은 번역 첨부)
형식: 자료당 — 제목·종류·출처·링크·확인 상태 / 왜 고르는가(한 줄) / 볼 것(1~2) / 오늘 적용(한 줄). 마지막에 「먼저 볼 것」 하나
금지: 중복 · 1년 지난 것 · 못 본 것을 본 것처럼 요약 · 확인 안 된 수치를 공식처럼
검증: 게시일·출처 표시. 확인 안 된 것은 「확인 필요」 표시
실행: Cron 매일 07:00 KST 자동 — 결과는 텔레그램으로만
```

실행 중인 스킬: [[library/skills/매일-자료검색-스킬]]

## 적용 2 — 대화록 (사서)

```text
목적: 오늘의 합의·결정을 나중의 나와 여섯 에이전트가 읽을 기록으로 남긴다
자료: 이 채팅 세션 — 전문이 아니라 맥락 · 합의 · 미결 · 연결
형식: conversations/YYYY-MM-DD-주제.md — topics: · ## 합의 · 결정 · 세 줄 세이브 · _index와 log 갱신
금지: 채팅 전문 덤프 · 논지 최종 확정 · map/log 과거 수정
검증: 깨진 링크 없음 · _index 최근·주제별에 등록됨
실행: 「대화록」 명령 또는 긴 세션 끝 — 초안 후 편집장 확인
```

## 적용 3 — 작품 기록 (art/)

```text
목적: 작품·시화를 집에 걸어 나중에 꺼내 쓴다
자료: 작품 원본(노션 갤러리) · 만든 날 · 매체 · (시화면) 시 구절
형식: art/ 노트 — 노션 링크 · 한 줄 · 연결. 원본은 노션, 위키는 링크·한 줄만
금지: 원본 대용량 직접 첨부 · 과도한 미화 · 작품 승격 자동 처리
검증: 링크가 열리는가 · 한 줄이 있는가
실행: 초안 먼저 → 편집장 승인 후 기록 (승격은 편집장)
```

## 사용법

1. 빈 뼈대를 복사해 여섯 칸을 채운다.
2. 막히면 AI에게 설계를 맡긴다:

```text
내 목적은 ○○이다.
목적·자료·형식·금지사항·검증 기준·실행 여부가 든 지시서를 설계해줘.
내 의도는 최소한으로 수정해.
```

3. 고칠 때는 최소 수정 — 「핵심 문장과 톤은 유지하고 필요한 부분만 고쳐」.

## 사서 인사이트 (초안)

여섯 칸 중 힘이 센 칸은 「검증 기준」과 「실행 여부」다. 목적·형식은 누구나 쓰지만, 검증을 지시서에 넣어야 아첨이 멈추고, 실행 여부를 넣어야 초안과 정식이 갈린다. 이 집의 `- [ ] 감수` 제도가 바로 「실행 여부」 칸의 일상형이다.
