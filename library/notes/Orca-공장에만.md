# Orca — 공장에만

## 내 한 줄

(초안) Orca는 위키에 들이지 않는다. 공장에 붙일지는 천천히 생각한다.

- [ ] 감수

## 지금 결정

- **사용 문제는 공장에만** 둔다. 위키(`오소풍_wiki` · `osopung/Repo` · inbox)에는 열지 않는다.
- **설치·실험은 보류.** 자리를 적어 두고, 천천히 생각한다.
- 원칙은 이미 ★5. [[library/notes/역할-병렬-결정|역할 · 병렬 · 결정]]

## 정체

Orca는 새 에이전트가 아니다. Stably AI의 **ADE** — 이미 있는 코딩 에이전트(Codex·Claude Code 등)를 Git worktree로 갈라, 한 작업장에서 동시에 돌리는 앱. 구독은 본인 것. 사이트 [onOrca.dev](https://onorca.dev) · [stablyai/orca](https://github.com/stablyai/orca).

본업은 **코딩 함대**. 후츠릿이 판단 비교에 쓴 것은 응용이다.

## 집과의 자리

| | 하는 일 | Orca |
|--|---------|------|
| **사서** | 맥 Cursor. 위키 소화·감수 | 같은 볼트를 열지 않음 |
| **헤르메스** | 수집·inbox | 공장 실험에 넣지 않음 |
| **고문** | 조언 | 집을 고치지 않음 |
| **코덱스** | 윈도우 공장. 집 Git·inbox 금지 | 공장 폴더를 붙인다면 여기 |

사령탑은 집 하나. Orca는 다섯 번째 HQ가 아니다.

## 붙인다면 (아직 실행 아님)

1. 위키 밖에 **공장 폴더**만. 그 폴더의 Git은 에이전트를 가르는 길. 집 Git은 그대로 코덱스 금지.
2. 윈도우 Orca에 그 폴더만 연다.
3. 작은 일 하나를 Codex·Claude에 동시에 주고, 편집장이 고른다.
4. 집에 넣을 글은 편집장이 사서에게 전한다. Orca는 inbox에 쓰지 않는다.

대가는 Git 울타리를 공장 쪽으로 다시 그리는 일, 토큰. 시간은 줄지 않고 사람 개입만 줄어들 수 있다.
