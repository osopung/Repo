# 연결 통로 — API와 MCP ★5

> 키워드: **5스타** · **5\*** · `star: 5`  
> 한 줄: **통로 = API, 플러그 = MCP.**

## 내 한 줄

(초안) 통로는 API다. MCP는 플러그에 불과하다. 콘센트가 없으면 플러그만 들고 있어도 전기는 안 온다.

- [ ] 감수

## 구분

《슈퍼휴먼 슈퍼워크》 용어 상자(34–35쪽)의 「연결 통로」는 **API**다. MCP가 아니다. 두 단이라 밑줄 노트에서 JSON·API·MCP가 한 덩어리로 섞였다.

| | 무엇인가 | 책에 가까운 말 |
|--|----------|----------------|
| **JSON** | 오가는 **메모 양식**. 이름과 값의 짝 | |
| **API** | 서로 다른 소프트웨어가 말하는 **연결 통로** | 항공사가 열어 둔 창구. 여행 AI가 표를 예매하려면 이 창구가 필요하다 |
| **MCP** | 그 통로들을 에이전트가 **같은 방식으로 꽂게 하는 표준 규약** | 「AI 시대의 앱스토어」 |

창구가 API이고, 그 창구를 에이전트 손에 맞게 규격화한 플러그가 MCP다. 조테로 MCP는 조테로 로컬 API라는 창구를, 법령 MCP는 법령 API라는 창구를, 커서가 같은 손짓으로 쓰게 하는 플러그다.

## MCP만으로 예매되는가

**안 된다.** MCP만으로는 항공사에 들어가지 못한다.

표를 예매하려면 항공사(또는 여행사) 쪽에 **창구가 있어야** 한다. 그게 보통 API다. MCP는 그 창구를 에이전트가 쓰기 쉽게 꽂는 플러그일 뿐이다. 벽에 콘센트가 없으면 플러그만 들고 있어도 전기는 안 온다.

창구가 REST API가 아닐 수는 있다. 브라우저로 예약 페이지를 누르는 도구를 MCP로 감쌀 수는 있다. 그래도 「항공사 시스템에 들어가는 길」은 있고, MCP는 그 길을 에이전트 손에 맞춘 것이다. 길이 없으면 MCP도 예매할 수 없다.
