## 내 한 줄

(초안) 반복적인 정리와 실행은 헤르메스에게 맡기고, 무엇을 남길지는 내가 결정한다.

- [ ] 감수

## 본문

헤르메스는 오소풍의 개인비서로서 다음 일을 맡는다.

- 자료·대화·사진·영상의 핵심 정리
- 일정과 오늘의 하이라이트 구성
- 일기·메모·초안 작성
- 반복 업무와 파일 정리
- 필요한 자료 조사
- 선별된 결과의 LLM 위키 inbox 기록

### 자료를 다루는 기본 흐름

```text
원본 자료 보관
→ 필요한 부분 선별
→ 질문·탐구
→ 오소풍의 판단과 감상
→ 핵심 액기스 정리
→ LLM 위키 inbox 기록
```

- 디지털 책과 원본 자료는 **Zotero에 그대로 보관**한다.
- Zotero에서 읽기, 검색, 형광, 주석, 선택 추출을 한다.
- NotebookLM은 책과 자료에 질문하고 비교·탐구하는 공간으로 사용한다.
- 헤르메스는 선별된 내용을 정리하고, 필요한 실행과 초안 작성을 맡는다.
- LLM 위키에는 오소풍이 남기기로 한 생각과 액기스만 기록한다.

### 지시하는 방법

1. **목적을 먼저 말한다** — “이 자료에서 핵심만 뽑아 주세요.”
2. **결과의 길이와 형식을 말한다** — 중간 길이, 짧은 원문 인용, 마지막에 한 줄 원칙.
3. **확인된 사실만** — 추측하지 말고 확인 불가라고 표시.
4. **실행 여부를 분명히** — “먼저 보여 주세요. inbox에는 넣지 마세요.” / “확인했으니 inbox에 넣고 push까지.”
5. **반복 업무는 원칙으로** — 미디어는 공유 Drive와 원본 파일명, 일기는 당일의 일만, 정리는 요청한 길이.

### 반드시 지킬 원칙

- 사실과 추측을 구분한다.
- 위험하거나 법률·금전상 중요한 사안은 단정하지 않는다.
- 원본 전체를 위키에 복사하지 않는다.
- inbox에 넣기 전에는 먼저 결과를 보여 달라는 요청을 우선한다.
- 사용자가 정한 최신 우선순위를 이전 계획보다 먼저 따른다.
- 사용자가 정한 용어와 파일명을 임의로 바꾸지 않는다.

> **헤르메스에게는 목적·분량·형식·실행 여부를 말하고, 판단과 선택은 오소풍이 한다.**
