## 내 한 줄

Hermes는 챗봇이 아니라 **상주·메신저형 실행 비서**이고, Cursor 사서와는 역할을 나눈다.

- [x] 감수

## 한 줄 정의

Hermes(Nous Research)는 단순 대화형이 아니라, **서버에 상주하며 파일·터미널·브라우저를 대신 돌리는 실행형 에이전트**. 코딩 짝꿍(Cursor)이나 단발 챗과 달리 **메신저로 부리는 ==24시간 개인 비서·자동화 일꾼**==에 가깝다.

## 왜 쓰나 (차별점 3)

1. ==**자기 개선 메모리·스킬** — 시행착오를 스킬로 남겨 다음 유사 작업에 재사용  
2. **모델 자유** — Claude/GPT/Gemini·OpenRouter·로컬 등 작업별로 교체 (본체≠모델)  
3. ==**원격·상시** — 텔레그램 등 + **Cron**(예약·반복 작업)

## 어디에 쓰기 좋은가

| 용도           | 예                         |
| ------------ | ------------------------- |
| ==주기 리서치==   | ==매일 뉴스·유튜브 요약 → 폴더에 md== |
| ==노트/파일 정리== | ==분류·태그·중복 정리 (범위 좁혀)==   |
| 메신저 ==심부름==  | ==밖에서도 짧은 지시·리마인드·초안==    |
| 서버 반복 작업     | 로그 점검·패턴 보고서              |

## Cursor(사서) vs Hermes

|     | Cursor 사서  | Hermes       |
| --- | ---------- | ------------ |
| 자리  | IDE·위키·감수  | 메신저·백그라운드 서버 |
| 방식  | 모니터 앞 상호작용 | 외출·꺼둔 모니터에도  |
| 기억  | 세션·위키 카드   | 에이전트 메모리·스킬  |
| 입구  | Cursor     | 텔레그램 등       |

**나눠 쓰기:** 위키 정리 = **맥 Cursor 사서** / 폰 수집 = **헤르메스** (`inbox/`) / 큰 화면 자문 = **고문** (`inbox/`만) / 오래 도는 제작 = **코덱스** (Git·inbox 없음).

## 쓰면서 지킬 TIP

- 작업 폴더·권한을 **좁혀** 시작 (샌드박스)  
- 가벼운 일 = 싼·빠른 모델, 무거운 일만 고급 모델  
- **메신저 연동**이 있어야 상시 비서로 의미가 큼  
- **Cron** = 정해진 시각에 알아서 도는 예약 작업 (지금 채팅과 별개)

## 편집장 현실 (2026-08-09 합의)

- 본체: Hostinger VPS · 입구: Telegram · 두뇌(현재): **GPT 5.6 Luna** (Nexos)  
- Google Drive·Calendar·Gmail 깊은 작업 → **Cursor 사서 플러그인** (VPS에서 개인 Drive OAuth 비추천)  
- 구글포토 원본은 포토/드라이브에 두고, 볼트에는 **선별 소량·링크**만  
- 위키 쓰기: Hermes는 **`inbox/`만** (Git A안)
