# 헤르메스 봇팀 ★5

> 검색: **5스타** · **5\*** · 헤르메스 · 봇팀 · Bot Mode  
> 출처: 2026-09-17 티타임즈TV · 김민정 HRX랩 — [자율형 AI에이전트 너무 쉬워졌다](https://www.youtube.com/watch?v=aaS2sVh-F10) · 봇 구간 18:51–30:52

## 내 한 줄

(초안) 헤르메스 봇팀은 본체를 여러 대 까는 일이 아니다. 프로필이 직원이 되고, 그룹 채팅을 열어야 같이 일한다.

- [ ] 감수

## 무엇인가

★5 [[library/notes/헤르메스-직원만들기|직원만들기]]가 **폴더가 직원**이라면, 봇팀은 그다음 층이다. **단톡이 팀**이다.

| 아닌 것 | 맞는 것 |
| --- | --- |
| 헤르메스 서버 다섯 대 | 본체는 **하나** |
| 챗창만 늘리기 | **프로필**이 직원, **그룹 채팅**이 팀 |
| 봇만 만들어 두기 | 단톡을 열어야 같이 움직인다 |
| 코덱스 한 창에서 혼자 치기 | 메인 봇이 다른 부서 봇을 **부른다** |

공식: [Bot Mode | Hermes Agent](https://hermes-agent.nousresearch.com/docs/user-guide/bot-mode)

## 두 덩어리 (영상)

**1. 텔레그램 원격 (18:51)**

노트북을 꺼도 텔레그램으로는 산다. 메인은 비서실장 봇 하나. 그 봇이 다른 봇을 부른다. 로그는 봇마다 따로 쌓여 정체성이 덜 흔들린다.

집의 본체는 이미 VPS다. 화면은 Desktop, 실행은 Hostinger. [[library/notes/헤르메스-데스크탑-개인환경-구분]]

**2. 단톡이 팀 (25:50)**

데스크톱 봇 모드로 역할별 봇을 두고, **선택 → Create → 그룹 채팅**을 연다. 영상 데모는 AI/AX 뉴스 제작실 — 치프 아래 리서치·인사이트·글·리뷰. 치프가 일을 나누고, 리뷰는 pass/revise. 사람은 올릴지·제목 오케이 같은 **개입 지점**만 본다. 역할은 봇마다 `SOUL.md`.

봇만 있으면 각자 존재할 뿐이다. 단톡을 열어야 팀이다.

## 집의 지금

봇 하나 · 본체 하나 · 프로필 `default` 하나. 이름이 헤르메스다.

많아지기 전에 **한 명을 먼저 제대로.** ★5 [[library/notes/스킬-먼저-Cron|스킬 먼저, 그다음 Cron]] · ★5 [[library/notes/헤르메스-직원만들기|직원만들기]]와 같다.

## 사서 인사이트 (초안)

영상은 뉴스 제작실을 보여 준다. 집에 가져올 것은 증식이 아니라 **폴더는 직원, 단톡이 팀**이라는 구분이다. 직원만들기 다음 층이지, 본체를 늘리는 층이 아니다.
