# 헤르메스 직원만들기 ★5

> 검색: **5스타** · **5** · 헤르메스 · 프로필  
> 출처: 2026-09-04 김효율 영상 공부 · [[_archive/youtube-에이전트-학습-천재적-방법-스크립트|스크립트]]

## 내 한 줄

헤르메스 직원은 본체를 여러 대 까는 일이 아니라, 고유한 아이디를 가진 프로필 폴더를 하나 더 만드는 일이다. 텔레그램내 헤르메스봇은 각자 필요하다.

- [x] 감수

## 무엇인가

영상 말 「고유한 아이디를 가진 개별 에이전트」「프로필을 분기」는 **챗창을 늘리는 것**이 아니다.


| 아닌 것          | 맞는 것                   |
| ------------- | ---------------------- |
| 헤르메스 서버 다섯 대  | 본체는 **하나**             |
| 챗GPT 스레드 다섯 개 | **프로필 폴더** 다섯          |
| 같은 봇에 별명만     | 직원마다 **아이디·기억·규칙**이 갈림 |


공식: [Profiles | Hermes Agent](https://hermes-agent.nousresearch.com/docs/user-guide/profiles)

## 직원이 되는 폴더

```text
~/.hermes/                    ← 지금 집의 헤르메스 (default)
~/.hermes/profiles/효리/      ← 새 직원
    SOUL.md                   이름·역할·하지 말 것
    MEMORY.md                 그 직원만의 기억
    스킬 · 크론
    모델 (코덱스 / 클로드 / Luna)
    텔레그램 봇 토큰
```

「고유한 아이디」는 이 **폴더 이름**이다.

## 만드는 세 층

김효율 영상은 버튼을 안 보여 주고 「대화하면서 분기하세요」로 넘긴다. 실제로는 셋이다.

1. **프로필을 만든다**
  대시보드 옆 프로필 전환 · 채팅 `/profile` · 서버 `hermes profile create 이름`.  
   복제(`--clone`)면 설정은 같고 기억만 비운다.
2. **그 직원만의 글을 넣는다**
  `SOUL.md`에 역할·해야 할 것·하지 말 것. [[library/notes/AI-직원을-만드는-핵심-인사이트|AI 직원]]의 정체성 층.
3. **텔레그램에 따로 보이게 한다**
  BotFather로 봇을 하나 더 만들고, **그 프로필의 토큰**에만 넣는다. 같은 토큰을 두 프로필에 넣으면 헤르메스가 막는다. 폰에 효1·효리처럼 **다른 칸**으로 보이는 이유다.

모델 연결은 그다음이다. 「코덱스와 연결된 헤르메스」는 그 직원의 **엔진**을 코덱스로 건 것이지, 프로필을 만든 일과 같지 않다.

## 코덱스에 건다는 것

김효율은 직원 대부분을 코덱스에 걸어 「토큰이 넉넉해서」라고 한다.

그 구독 한도는 **코덱스 앱 안의 이용권**이다. VPS 헤르메스가 쓰는 Nexos 크레딧과 **한 줄이 아니다.** ★5 [[library/notes/글쓰기-Claude-비용-Pro-vs-API|Pro ≠ API]]와 같다.

집을 코덱스에 걸면 이미 낸 토큰이 공짜로 흐르지 않는다. VPS에서 쓰려면 API를 또 꽂거나, 본체를 윈도우 공장으로 옮겨야 한다. 둘 다 방 나눔을 깬다.


|         | 김효율                  | 집                            |
| ------- | -------------------- | ---------------------------- |
| 연결      | 헤르메스가 코덱스를 **직접 부름** | 둘이 **전선으로 안 묶임**             |
| 헤르메스 두뇌 | 코덱스(효삼만 클로드 코드)      | **Luna (Nexos)**             |
| 코덱스 자리  | 헤르메스 직원의 실행기         | 윈도우 **공장** `osopung/Factory` |




## 집의 지금

봇 하나 · 본체 하나 · 프로필 `default` **하나**. 이름이 헤르메스다.

대시보드: [https://hermes-agent-noxp.srv1886227.hstgr.cloud](https://hermes-agent-noxp.srv1886227.hstgr.cloud)

많아지면 그때 프로필로 나눈다. **한 명을 먼저 제대로.** [[library/notes/스킬-먼저-Cron|스킬 먼저, 그다음 Cron]]과 같다. 직원이 안정되기 전에 다섯을 복제하지 않는다.

## 사서 인사이트 (초안)

영상은 직원 열 명을 자랑한다. 집에 가져올 것은 증식이 아니라 **폴더가 직원이다**는 구분이다. 대화창·본체·엔진을 한 말로 섞지 말 것.
