# 매일 자료 검색 스킬 초안

> 사서 검토 전 초안입니다. 특정 테마가 아니라, 그날의 목적에 맞춰 자료 검색 방법을 바꾸는 범용 절차를 제안합니다.

## 목적

매일 아침 오소풍님이 정한 오늘의 활동과 주제에 맞춰, 바로 읽거나 보고 적용할 수 있는 자료를 적은 수만큼 찾습니다.

자료를 많이 모으는 것이 목적이 아닙니다. **오늘의 작업에 실제로 도움이 되는 자료와 오늘 적용할 한 가지를 찾는 것**이 목적입니다.

## 기본 흐름

```text
오늘의 활동과 목적 확인
→ 검색어와 자료 유형 결정
→ 출처 우선순위에 따라 검색
→ 실제 내용 확인
→ 중복 자료 제거
→ 오늘 활용할 자료만 선별
→ 적용할 한 가지 제시
```

## 1. 검색 전에 확인할 것

- 오늘 할 일 또는 시간 블록
- 오늘의 관심 주제
- 자료를 활용해 만들 결과물
- 원하는 자료 유형: 이미지·영상·문서·기사·공식자료 등
- 필요한 자료 개수
- 기간·언어·출처 등의 제한

정보가 충분하면 바로 검색합니다. 검색 방향이 크게 달라질 때만 짧게 질문합니다. 주제가 정해지지 않았다면 임의로 결정하지 않고, 오늘 활동을 기준으로 삼은 가정을 밝힙니다.

## 2. 테마에 맞춰 검색 방법 바꾸기

### 창작·미술

작품명, 작가명, 재료·기법, 구도·여백·색채, 전시·작품 아카이브를 조합합니다.

### AI·기술

공식 문서, 실제 사용 사례, 튜토리얼, 비교·검증 자료를 우선합니다.

### 글쓰기·독서

원문, 작가 인터뷰, 강연, 서평·비평, 문장·구성 분석 자료를 찾습니다.

### 투자·시장

운용사·거래소 등 공식 자료와 기준일이 확인되는 자료를 우선합니다. 공식 수치와 해석을 구분합니다.

검색어는 다음 순서로 확장합니다.

```text
핵심 주제
→ 핵심 주제 + 사례
→ 핵심 주제 + 실습
→ 핵심 주제 + 공식자료
→ 핵심 주제 + 오늘 만들 결과물
```

## 3. 자료 검증

제목이나 검색 결과 요약만 보고 내용을 단정하지 않습니다. 가능한 범위에서 다음을 확인합니다.

- 원문·영상·이미지에 실제로 접근했는가
- 제목과 작성자·채널이 확인되는가
- 게시일 또는 업데이트 시점이 확인되는가
- 오늘의 주제와 직접 관련되는가
- 바로 배울 내용이나 적용점이 있는가

확인 범위는 분명히 표시합니다.

- 내용 확인 후 추천
- 제목·메타데이터 기준 추천
- 원문 접근 제한
- 추가 확인 필요

확인하지 못한 내용을 본 것처럼 요약하지 않습니다.

## 4. 자료 선별 기준

다음 기준으로 자료를 고릅니다.

1. 오늘의 활동과 직접 연결되는가
2. 오늘 바로 적용할 수 있는가
3. 다른 자료와 내용이 겹치지 않는가
4. 출처와 링크가 분명한가
5. 분량과 난이도가 적절한가

요청한 개수는 정확히 지킵니다. 자료의 역할은 가능하면 다음처럼 나눕니다.

```text
개념 이해용
→ 실제 사례용
→ 오늘 적용용
```

## 5. 자료별 제시 형식

```markdown
## 자료 제목

- 종류:
- 출처:
- 링크:
- 확인 상태:

### 왜 고르는가
오늘의 활동과 연결되는 이유를 짧게 씁니다.

### 여기서 볼 것
핵심적으로 확인할 부분을 한두 가지로 제한합니다.

### 오늘 적용
오늘 바로 해볼 수 있는 작은 실천을 한 줄로 씁니다.
```

자료를 여러 개 제시할 때는 먼저 학습 순서를 짧게 보여줍니다.

```text
개념 이해 → 사례 확인 → 직접 적용
```

## 6. 자료 유형별 주의점

### 이미지·작품

실제 이미지를 확인한 뒤 구도, 글씨와 이미지의 관계, 여백, 색채, 농담과 질감을 분석합니다. 이미지를 확인하지 못했으면 제목만으로 기법을 단정하지 않습니다.

### 유튜브

가능하면 자막·영상 설명·공식 페이지를 확인합니다. 자막이나 본문을 확보하지 못하면 제목만으로 영상 내용을 요약하지 않습니다.

### 공식·기술 자료

공식 문서, 실제 사례, 튜토리얼, 개인 의견 순으로 우선합니다. 공식 설명과 개인 해석을 구분합니다.

### 투자·금융

기준일과 출처를 표시합니다. 확인되지 않은 수치를 공식 수치처럼 말하지 않으며 투자 판단을 대신하지 않습니다.

## 7. 출처와 권리

외부 자료에는 제목, 작성자·채널, 게시일 또는 확인일, 원문 링크를 붙입니다. 출처가 불분명한 이미지와 작품은 개인 연습·참고용으로만 안내하고 공개·상업적 사용을 권하지 않습니다.

## 8. 기록과 선택권

자료 검색 결과를 위키나 파일에 자동 기록하지 않습니다. 오소풍님이 명시적으로 요청할 때만 기록합니다.

마지막에는 다음 중 하나만 간결하게 제시합니다.

- 오늘 가장 먼저 볼 자료 1개
- 오늘 적용할 원칙 1개
- 짧은 우선순위

최종적으로 무엇을 공부하거나 선택할지는 오소풍님이 결정합니다.

## 완료 기준

- 요청한 개수만큼 자료를 선별했습니다.
- 각 자료의 출처와 링크를 확인했습니다.
- 확인한 내용과 추정을 구분했습니다.
- 자료마다 오늘 적용할 포인트를 붙였습니다.
- 자료 간 역할이 지나치게 겹치지 않습니다.
- 사용자가 바로 시작할 수 있는 우선순위를 제시했습니다.
