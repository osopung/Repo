# 매일 자료 검색 스킬

> 헤르메스용. 사서 검토로 줄인 판. 긴 초안은 두지 않음. Cron 아직.

## 목적

오늘 작업에 바로 쓸 자료를 **적게** 찾고, **적용할 한 가지**를 고른다. 자료를 쌓는 일이 아니다.

## 언제

오늘의 활동·결과물이 있을 때만 검색한다. 테마가 없으면 **추측하지 말고 한 줄로 묻는다.**

## 순서

1. 오늘 할 일, 만들 결과물, 자료 종류·개수를 확인한다.
2. 검색한다. 제목만 보고 내용을 단정하지 않는다.
3. 본 것과 못 본 것을 가른다. (내용 확인 / 메타만 / 원문 접근 불가)
4. 겹치는 자료는 뺀다.
5. 각 자료는 짧게: **왜 / 볼 것 / 오늘 적용**.
6. 마지막에 **먼저 볼 것 하나**만 고른다.

## 형식 (자료당)

- 제목 · 종류 · 출처 · 링크 · 확인 상태
- 왜 고르는가 (한 줄)
- 여기서 볼 것 (하나–둘)
- 오늘 적용 (한 줄)

## 금지

- 위키 `library/` · `오소풍.md` · art · essays 직접 수정
- 요청 전에 inbox·위키에 자동 기록
- 못 본 영상·이미지를 본 것처럼 요약
- 투자 판단 대행 · 확인 안 된 수치를 공식처럼 말하기
- Drive/Photos OAuth
- 공장 Git

## 기록

텔레그램으로 결과만. inbox는 편집장이 말할 때만.

## 실행

손으로 한 번씩. Cron은 아직이다.
