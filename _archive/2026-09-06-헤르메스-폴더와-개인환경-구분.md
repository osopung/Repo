## 내 한 줄

(초안) **헤르메스 Desktop에 보이는 폴더는 내 개인 자료가 아니라, 원격 VPS에서 실행되는 헤르메스 프로그램과 작업 환경의 일부다.**

- [ ] 감수

## 오늘 확인한 것

Hermes Desktop을 Remote Gateway로 연결한 뒤, 오른쪽 파일 탐색기에 `HERMES`라는 프로젝트 폴더와 여러 하위 폴더가 보였다. 처음에는 이것이 개인 프로필이나 개인 기록 폴더인지 궁금했지만, 실제로는 Hermes 프로그램의 소스코드 저장소에 가까운 구조였다.

이 폴더에는 다음과 같은 개발·실행 구성요소가 들어 있다.

- `agent` — AI 에이전트의 핵심 기능
- `apps` — Desktop 등 애플리케이션
- `gateway` — Telegram과 Desktop 등이 연결되는 백엔드
- `hermes_cli` — Hermes 명령줄 프로그램
- `cron` — 예약 작업
- `plugins` — 플러그인
- `providers` — AI 모델 제공자 연결
- `skills` — 에이전트가 사용하는 스킬
- `tools` — 에이전트 도구
- `web`, `ui-tui` — 웹·터미널 사용자 화면
- `tests-js`, `scripts` — 테스트와 개발용 스크립트
- `docker`, `native` — 배포와 플랫폼 관련 구성

따라서 이 `HERMES` 폴더는 개인 사진·일기·기억을 보관하는 곳이 아니라, **헤르메스라는 프로그램의 제작소 또는 본체 창고**라고 이해하는 것이 맞다. 내용을 함부로 수정하거나 삭제하면 Hermes 실행에 영향을 줄 수 있으므로 직접 손대지 않는 것이 안전하다.

## 폴더와 개인 환경을 한눈에 구분하기

오른쪽 파일 탐색기에 보이는 `HERMES` 프로젝트 폴더와 그 안의 파일들은 오소풍님의 개인 자료나 기억 폴더가 아니다. 다음처럼 이해하면 된다.

| 구분 | 역할 | 예시 |
|---|---|---|
| 프로그램 소스코드 | Hermes 자체를 만들고 실행하는 구성요소 | `agent`, `apps`, `gateway`, `hermes_cli` |
| 실행·확장 구성 | 예약 작업, 플러그인, 모델 연결, 스킬과 도구 | `cron`, `plugins`, `providers`, `skills`, `tools` |
| 화면·배포·검사 | 웹·터미널 화면, 배포, 테스트와 개발 지원 | `web`, `ui-tui`, `docker`, `native`, `tests-js`, `scripts` |
| 개인 Hermes 환경 | 오소풍님의 운영 원칙, 사용자 정보, 기억, 설정 | `/opt/data/SOUL.md`, `/opt/data/memories/USER.md`, `/opt/data/memories/MEMORY.md`, `/opt/data/config.yaml` |
| 개인 작업 저장소 | 오소풍님의 위키와 inbox 기록 | `/opt/data/Repo` |

한마디로 말하면, 오른쪽 `HERMES`는 **프로그램 제작소**이고 `/opt/data`와 `/opt/data/Repo`는 **오소풍님이 사용하는 개인 작업 환경**이다.

## 개인 환경과의 구분

오소풍의 개인 운영 정보와 작업 자료는 소스코드 폴더와 구분되어 있다.

- `/opt/data/SOUL.md` — Hermes 운영 원칙
- `/opt/data/memories/USER.md` — 오소풍의 선호와 사용자 정보
- `/opt/data/memories/MEMORY.md` — 장기적으로 참고할 기억
- `/opt/data/config.yaml` — Hermes 설정
- `/opt/data/Repo` — 오소풍 위키의 Git 저장소
- `/opt/data/cron` — 자료 큐레이션 등 예약 작업의 실행 자료

이번 Desktop은 **Hostinger VPS라는 Remote Gateway**에 연결되어 있다. 따라서 Desktop은 화면을 제공하지만, 파일 탐색·세션·도구·Cron의 실제 실행은 VPS의 Hermes 환경에서 이루어진다.

## 프로필·게이트웨이·Artifacts

- **Remote Gateway**는 Hermes가 실행되는 원격 백엔드다. 현재 이름은 `Hostinger VPS`로 표시된다.
- **프로필**은 `Ctrl + K` 명령 팔레트의 `Profiles`에서 확인·전환할 수 있다. 왼쪽 패널에 항상 노출되는 것은 아니다.
- **Artifacts**는 Hermes가 작업 중 만든 파일·이미지·링크·자료 결과물을 모아 보여 주는 보관함이다. 오늘 아침 자료 큐레이션 결과가 Desktop의 Artifacts에 보인 것도 같은 Remote Gateway의 작업 결과가 표시되었기 때문이다.

## 정리

Desktop에서 보이는 모든 폴더가 오소풍의 개인 기록은 아니다. 먼저 그것이

1. Hermes 프로그램 소스코드인지,
2. VPS의 개인 설정·기억인지,
3. 위키 작업 저장소인지,
4. Artifacts처럼 생성 결과를 보여 주는 화면인지

구분해야 한다.

> **화면은 Desktop에 있지만, 지금 작동하는 헤르메스의 본체와 개인 환경은 Remote Gateway인 Hostinger VPS에 있다.**
