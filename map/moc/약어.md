# 약어

> 검색: **약어**  
> 플러그인: **Abbreviations and Acronyms** (`abbreviations-mark`) — 노트에 나온 약어에 커서를 올리면 풀이.  
> **사서 규칙:** 편집장이 약어를 물으면 → 짧게 풀이한 뒤 **이 목록 + Extra + 플러그인 `data.json` 전역**에 알아서 추가한다. (이미 있으면 스킵)

## 쓰는 법

1. **전역** — 설정 → Abbreviations and Acronyms → Manage abbreviations (또는 아래 Extra 정의 · `globalFile` = 이 파일)
2. **노트별** — frontmatter에 `abbr:` 목록, 또는 Extra: `*[MOA]: Mixture of Agents — …`
3. 수동 HTML도 가능: `<abbr title="…">MOA</abbr>`

옵시디언을 한 번 **재시작**(또는 플러그인 끄고 켜기)한 뒤, 읽기/라이브프리뷰에서 **MOA** 등에 커서를 올려 보세요.

| **Zotero** | Zotero (조테로) | 논문·도서·웹 출처 문헌 관리 |
| **VCS / Git** | Version Control (Git) | 파일 이력·되돌리기 |
| **ff-only** | git pull --ff-only | fast-forward only. 이력이 갈라지지 않았을 때만 당김. 갈라지면 코덱스가 맞춤 |

## 위키 전용

| 말 | 뜻 |
|----|-----|
| **weekly** | `YYYY-MM-Wn` | 그달의 월요일 시작 주. 그달 첫 월요일 주 = W1. 예: [[map/weekly/2026-08-W4\|2026-08-W4]] = 8/24–30 |
| **monthly** | `YYYY-MM` | 그달의 월간. 주간을 기준으로 한 일·계속·나중에·내려놓을 일. 예: [[map/monthly/2026-08\|2026-08]] |
| **inbox** | 일단 쏟아붓는 입구 |
| **ingest** | inbox → `library/notes/` 재탄생 (핵심·사서 인사이트 초안). 원본은 `_archive` |
| **감수** | 「내 한 줄」을 편집장이 확정 |
| **5스타 / ★5** | 중요 노트. 목록: [[map/moc/5스타\|5스타]] |
| **팬픽** | fan fiction. 팬이 세계 안에 들어가 빈칸을 채우는 글쓰기. ★5 [[library/notes/팬픽-빈칸을-채우는-글쓰기\|팬픽]] |
| **프리퀄** | prequel. 본편보다 앞선 이야기 |
| **사서** | 맥 Cursor 에이전트 |
| **편집장** | 오소풍(사람) |
| **헤르메스** | **뇌.** 24시간 그림자 비서 (Telegram·VPS) |
| **프로필 분기** | 헤르메스 직원만들기. 본체 복제가 아니라 고유 아이디 폴더. ★5 [[library/notes/헤르메스-직원만들기\|헤르메스 직원만들기]] |
| **코덱스 토큰** | 헤르메스가 챗GPT Plus/Pro 구독으로 머리 전기를 씀. 호스팅어 아이디 분리가 아님. ★5 [[library/notes/헤르메스가-코덱스-토큰쓰기\|헤르메스가 코덱스 토큰쓰기]] |
| **고문** | 윈도우 Cursor. **위키전담.** inbox pull·push. 사서·공장 아님 |
| **코덱스** | **손발.** 윈도우 로컬. 공장 `osopung/Factory`(Cursor Cloud와). 집 Git·inbox 금지. 비밀 파일 커밋 금지 |
| **뇌·손발** | 헤르메스=뇌, 코덱스=손발. AI가 일을 끝낼 환경 |
| **Cursor Cloud** | 공장 레포. 고문이 아님 |
| **바이브 코딩** | vibe coding. 목적·구조를 정하고 AI 구현을 지휘. [[library/ideas (생각의 축)/바이브-코딩\|바이브 코딩]] |
| **하네스** | harness. 에이전트의 책상. 도구·파일·세션 (Claude Code·Codex) |
| **AI 네이티브** | AI Native. 챗을 곁에 두는 게 아니라, 역할·기억·규칙·일정으로 AI 직원이 일을 끝내는 운영. [[library/notes/AI-직원을-만드는-핵심-인사이트]] |
