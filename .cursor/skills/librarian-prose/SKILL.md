# 사서 글 — 여백과 문단

글을 보기 쉽게 여백을 충분히 두고 문단을 끊어 정리하라.

집 원천: `library/skills/사서-스킬-글-여백.md`

## 매번

채팅 · 위키 노트 · 스크립트 · daily · 로그. 예외 없음.

문단과 문단 사이, 번호와 번호 사이에 **빈 줄을 둔다.**

번호 바로 아래 설명(~3줄)은 **붙인다.** 번호와 설명 사이에 빈 줄을 넣지 않는다.

표로 몰아쓰지 않는다. 한 덩어리로 붙이지 않는다.

한 문장마다 줄을 바꾸지 않는다. 한 숨의 말은 붙여 두고, 숨이 바뀌면 문단을 끊는다.

스크립트·자막은 타임스탬프(` [mm:ss] `) 한 덩어리마다 빈 줄. 말은 고치지 않는다.

## 예

아님:

```
1. 첫째. 설명이 바로 이어지고 2. 둘째도 붙어 있다.
```

맞음:

```
1. 첫째.

   설명은 바로 아래 두세 줄. 빈 줄 없이 붙인다.

2. 둘째.

   번호와 번호 사이만 띄운다.
```
