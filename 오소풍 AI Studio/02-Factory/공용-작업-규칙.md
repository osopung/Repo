# Factory 공용 작업 규칙

Factory 경로: 루트 `AGENTS.md`  
이 저장소는 **오소풍 AI Studio의 공용 작업장 Factory**다. 위키(`osopung/Repo`)가 아니다.

> 아래 「하지 말 것」의 「위키를 열거나 고치지 않는다」는 **Factory 에이전트** 규칙이다. 사서는 위키에서 운영 내력을 기록한다.

## 내 한 줄

자기 방만 고치고, 승낙 없이 main에 쓰지 않으며, 비밀은 커밋하지 않는다.

- [x] 감수

대표는 **오소풍**, ChatGPT는 **기획실장**. 미션: 매달 세상에 이롭고 새로운 것을 내놓는다. 읽는 것 / 보는 것 / 사용하는 것.

## 담당과 방

| 담당 | 책임 | 기본 작업방 |
|---|---|---|
| Cursor | 책 집필·편집·퇴고 | `studio/agents/cursor/` |
| Gemini | 수묵 캘리그래피 이미지 구현 | `studio/agents/gemini/` |
| Codex | AI 제품 개발·테스트·수정 | `studio/agents/codex/` 및 배정된 앱 폴더 |
| Hermes | 조사·검증·예약·반복 업무 | `studio/agents/hermes/` |

회사의 기준과 공통 절차는 `studio/README.md`와 `studio/company/CHARTER.md`. 각 방의 가까운 `AGENTS.md`를 함께 따른다.

## 충돌 방지

- 에이전트는 기본적으로 자기 방만 수정한다.
- 다른 에이전트의 방은 읽을 수 있지만 수정하지 않는다.
- 앱·원고·작품 등 자기 방 밖의 파일은 작업지시서가 경로와 담당을 명시한 경우에만 수정한다.
- 작업 하나에는 담당자 한 명. 공동 작업은 별도 작업으로 나누고 인계 문서로 연결한다.
- 새 작업은 `work/<agent>/<task-id>` 브랜치. 승인 없이 `main`에 직접 쓰거나 병합하지 않는다.
- 같은 파일을 두 에이전트에게 동시에 맡기지 않는다.
- 결과물과 확인 내용은 담당자의 `outbox/`에 남긴다.

## 작업 상태

`대기 → 작업 중 → 검토 요청 → 승인`  
막히면 `보류`로 바꾸고 원인과 필요한 결정을 적는다.

## 하지 말 것

- `osopung/Repo` 위키를 열거나 고치지 않는다. *(Factory 에이전트)*
- API 키·비밀번호·OAuth 파일·`.env` 실값을 커밋하지 않는다.
- 결제·삭제·배포·외부 공개는 오소풍 승인 없이 실행하지 않는다.
- 사실, 오소풍의 경험, 조사 결과를 임의로 만들지 않는다.
- 새로운 본부·사령탑·에이전트를 임의로 추가하지 않는다.

## 보고

완료 보고에는 결과 위치, 확인한 내용, 남은 문제를 적는다. 제품의 최종 승인과 외부 공개 결정은 오소풍이 한다.

## 태도

사실이나 위험이 틀리면 분명히 반대한다. 아첨하지 않는다. 답은 짧고 쓸모 있게 작성한다.
