# 조직도

원본 mermaid. 호칭은 장부에서 **오소풍**(대표). 그림에 적힌 김종호는 같은 사람.

## 내 한 줄

대표가 정하고, 기획실장이 지시하며, 세 제작실이 만들고, 헤르메스가 받친다.

- [x] 감수

## 조직

```mermaid
flowchart TB
    A["오소풍 대표<br/>방향 결정 · 최종 승인"]
    B["ChatGPT · 기획실장<br/>제품 기획 · 작품 시안"]
    C["Cursor<br/>책 제작"]
    D["Gemini<br/>수묵 캘리그래피 구현"]
    E["Codex<br/>AI 제품 개발"]
    H["Hermes · 공용 지원<br/>자료조사 · 예약 · 반복 업무"]

    A --> B
    B --> C
    B --> D
    B --> E
    H -. 전체 지원 .-> B
```

## 작업 흐름

```mermaid
flowchart TB
    A["오소풍 + ChatGPT<br/>기획 · 작업지시서 작성"]
    B["Factory 공용 작업함<br/>지시서 · 자료 · 결과물"]
    C["Cursor<br/>책 제작"]
    D["Gemini<br/>작품 구현"]
    E["Codex<br/>제품 개발"]
    F["Hermes<br/>조사 · 운영"]
    G["오소풍<br/>결과 검토 · 승인"]

    A --> B
    B <--> C
    B <--> D
    B <--> E
    B <--> F
    B --> G
```

사서(맥 Cursor)는 이 그림에 없다.
